# 自备壁纸放这里

控制面板 → 外观 → 壁纸，除了「默认（Win10 蓝）」之外的三张需要你自己放图。

## 需要补的文件

| 壁纸 | 文件名 |
|---|---|
| 极光 | `aurora.jpg` |
| 山脉 | `mountains.jpg` |
| 抽象几何 | `abstract.jpg` |

⚠️ **每张只要一个文件，不要 `-dark` 版。** 这三张是「单图模式」，亮色和暗色主题共用同一张图。

只有「默认」那张是特殊的 —— 它用的是仓库根目录的 `wallpaper.jpg` / `wallpaper-dark.jpg`，那是 Win10 官方的两张壁纸，所以保留亮暗两版。

## 说明

- **没放图也不会坏事。** 控制面板里那张卡片会显示成「＋ 待补充」并且**点不动** ——
  这是故意的：如果允许点，`data-wallpaper` 会指向一张 404 的图，
  壁纸层什么都画不出来，你会看到整个桌面变成纯色，以为把系统点坏了。

- **尺寸建议** 1920×1080 以上，横构图。文件建议压到 300KB 以内
  （壁纸是首屏最大的一张图，太大会拖慢加载）。

- **暗色模式下会有点偏亮**：同一张图在深色界面里大面积出现，通常比在浅色界面里刺眼。
  如果介意，选图时挑一张本身偏暗的，或者在图片上自己压一层暗角。

- 放好之后**不用改代码**，刷新页面就能在控制面板里看到缩略图。

## 想换成自己的图 / 加新壁纸

壁纸清单在 `src/lib/wallpaper.ts` 的 `WALLPAPERS` 数组里，
加一项 `{ id, nameKey, image }` 就行。

⚠️ 但 CSS 里的 `[data-wallpaper="xxx"]` 规则**还是得手动加一条**
（因为 Tailwind 扫不到运行期拼出来的类名）。
见 `global.css` 里「壁纸切换」那一节。
